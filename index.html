What the calculation includes

One wrap and two circular end caps per straight tube, plus 16 reinforcement patches. The optional canopy uses two flat rectangular panels. Packing uses fixed grain direction and 8 mm spacing, not optimal nesting.

Ports, valves, seam-seal tape, damaged test coupons and inflation compensation are excluded. The tube intersections are schematic. This is not a pressure, structural or drainage simulation. DXF contains nominal cutting curves, not router G-code.

EVERYTHING TOGETHER

Ready for GitHub Pages.

The package is a buildless HTML / CSS / JavaScript project. It needs no API key, backend, npm install or paid service.

  1. Unzip the project.
  2. Upload all its files and folders into a GitHub repository, keeping index.html at the root.
  3. In repository Settings → Pages, select Deploy from a branch → main → /(root), then Save.
  4. Open the GitHub Pages URL when GitHub finishes publishing.

For local use, open index.html, or serve the folder with python3 -m http.server 8000. The included mesh studio works offline with its bundled assets and supports OBJ, STL and 3DM files with saved meshes.
